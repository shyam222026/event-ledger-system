How to help:
- Run builds with `mvn clean verify` to validate changes.
- Prefer minimal, focused changes in the parent POM to configure tooling.
- Do not run heavy integration tests unless requested.

Helpful files:
- Parent POM: pom.xml
- Modules: `event-gateway`, `account-service`

Examples of tasks:
- Add CI tooling (JaCoCo, Checkstyle)
- Fix build errors and run unit tests
- Create or update `prompt.md` / `instructions.md` to explain AI expectations

Contact: Maintain concise, actionable updates. Use the repo root for metadata files.
